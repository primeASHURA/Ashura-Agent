# Ashura AI

<img src="docs/images/ashura.png" alt="Ashura AI avatar" width="112">

Ashura AI is a native Android coding assistant built with Kotlin and Jetpack Compose. Choose a project folder, configure a model provider, and switch to Agent mode to inspect or edit workspace files.

- Stream chat responses and see workspace actions as they run.
- Choose a model provider and manage project conversations locally.
- Review, search and edit project files with configurable approvals.
- Deploy prepared static websites through supported providers.

## Build and run

See the [setup guide](docs/SETUP.md) for Android Studio, command-line builds, first launch and GitHub publishing.
